# 使用风险与合规说明

本文件说明本项目的技术边界、可能失效的场景和使用风险。它不构成法律意见；如果你不
同意以下内容，请不要运行本项目。

## 项目做什么

- 通过 Windows 屏幕截图（GDI/BitBlt）读取游戏窗口中的像素。
- 在本地做图像识别：英雄名、流派图标、白色符文、字模兜底。
- 在本地知识库中检索攻略并计算推荐分，结果只显示在浮窗或本地网页里。

## 项目不做什么

- 不读取、修改或注入游戏进程内存。
- 不修改游戏文件、资源或配置。
- 不模拟键鼠、不自动选人、不自动对局、不代替玩家操作。
- 不绕过反作弊、不破解、不分发游戏本体或未授权的美术资源。
- 默认不联网；只有在用户主动配置 AI 点评时才会向所选服务发送文本。

## 可能失效或被拦截的场景

- 游戏使用**独占全屏**：浮窗可能无法置顶，GDI 也常抓不到画面。请改用“无边框窗口”或
  窗口化模式。
- 游戏或系统启用**受保护画面**、HDCP、反作弊渲染保护：截图可能返回黑屏或空帧。
- 显卡驱动、远程桌面、虚拟机、HDR、缩放比例变化：颜色和坐标可能偏移。
- 游戏 UI 改版：名单位置、字体、图标样式变化会导致识别失败；本项目会尽量返回“未识
  别”，而不是编造结果。

## 账号与社区规则风险

- 本项目与游戏开发商、发行商和社区无关，不是官方工具。
- 即使本项目只读屏幕，部分游戏的用户协议或反作弊策略仍可能把第三方辅助工具视为违
  规。是否使用、是否可能被警告或封禁，由用户自行判断并承担风险。
- 请先确认你所在地区、游戏版本和社区规则允许此类辅助工具；不要在对局中影响其他玩家
  的公平体验。
- 不建议在排位、比赛或任何有奖惩的环境中使用；如果游戏提示异常，请立即停止。

## 数据与隐私

- 识别和推荐默认完全离线，截图不会上传。
- 开启可选 AI 点评后，发送的是英雄名、流派和知识库摘要等文本，不包含原始截图；具体
  以你所配置服务的隐私政策为准。
- 本地会保存设置、浮窗位置和少量运行统计；可用 `.gitignore` 中列出的路径自行清理。
