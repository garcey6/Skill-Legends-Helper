# Roadmap

这些是后续可以做的方向，不是当前承诺。优先级会按实际使用反馈调整。

## 截图与兼容性

- **WGC / DXGI 截图**：用 Windows Graphics Capture 或 Desktop Duplication 替换 GDI，进一步兼容硬件加速和独占全屏。
- **更多窗口模式**：适配不同游戏启动器、无边框工具和多显示器切换。
- **截图失败自动降级**：在 BitBlt / PrintWindow 都失败时给出更具体的诊断。

## 浮窗交互

- **浮窗内修正**：识别错时直接在浮窗里下拉改英雄，不用切网页。
- **可选的点击穿透模式**：在保留拖动的前提下，提供锁定/穿透开关。
- **更紧凑的卡片布局**：为小屏幕或超宽屏提供不同排版。

## 识别能力

- **视觉大模型兜底**：未知英雄或新 UI 时，把头像区域发给 VLM 识别。
- **全英雄自动识别模板**：补齐 60 个头像模板，减少手动学习。
- **宝物识别**：用同样的图标 + 文字模板扩展到对局中期的宝物三选一。
- **流派面板自适应**：UI 改版后自动重新定位红环和网格。

## 数据与复盘

- **对局复盘**：保存每局识别结果和名次，形成个人版本胜率。
- **攻略版本筛选**：按游戏版本过滤知识库条目。
- **Embedding 检索**：攻略量大后，把 BM25 换成 bge / text-embedding 混合检索。
- **攻略贡献流程**：让社区提交的构筑更容易审核、去重和合并。
