# 故障排查

按「启动 → 识别 → 显示 → 性能 → 端口 / 网络 → 数据」分类。先做三个基础检查：

1. 当前页面是从 `http://127.0.0.1:8777/library`（或控制台实际端口）打开的，不是直接双击 HTML 文件。
2. 只有**一个**助手实例在运行；旧控制台没有残留。
3. 浏览器按过 `Ctrl+F5`，并确认控制台第一屏的实际快捷键。

## 启动

### 双击 `启动助手.bat` 后窗口一闪而过

- 在 PowerShell 中运行 `启动助手.bat`，看完整报错。
- 检查 Python 是否有 `numpy / Pillow / tkinter`：

```powershell
python -c "import numpy, PIL, tkinter; print('ok')"
```

- 依赖缺失时执行 `python -m pip install -r requirements.txt`。
- 启动器找不到 Python 时，安装带 Tkinter 的官方 Python 3.10+，或使用 DSH 自带运行时。

### 提示「浮窗助手已经在运行」

说明旧实例还占着单实例锁。关闭旧控制台，或在旧浮窗上按实际退出键（默认 `Ctrl+Alt+Q`）。确认任务管理器里没有残留 `python.exe` 后再启动。

### 启动后没有网页控制台

- 可能用了 `--no-server`，或启动的是纯浮窗进程。
- 看控制台第一屏「设置与攻略库」地址。
- 没有地址时，用 `python run.py --no-browser --port 8777` 单独启动网页控制台。

## 识别

### 没有自动出结果 / 按 `Alt+C` 也没反应

- 正常不需要按 `Alt+C`：进入选人界面后自动识别；`Alt+C` 只是强制重算。
- 先看控制台是否打印「自动识别已开启」和 `[live]`；旧进程可能还在跑旧版，关闭并重启。
- 自动抓帧只认标题包含「选技大乱斗 / Skill Legends / 选技」的窗口；确认游戏窗口标题正常。
- 确认底部 8 个书包图标和顶部前 3 个名牌完整；画面还在动画时等稳定。
- 如果控制台报 `window_not_found`，说明没有找到标题匹配的游戏窗口；报 `black_frame` 则先切无边框窗口。
- 手动键被占用会自动换键，以控制台和浮窗待机卡为准（见 [INSTALL](INSTALL.md#命令行参数)）。

### 截图黑屏 / 浮窗不显示

九成是游戏使用了**独占全屏**。Windows 不允许普通置顶窗口覆盖独占全屏，GDI 截图通常也会得到黑屏。把游戏改成「窗口化」或「无边框全屏 / Borderless」。

如果窗口模式仍然黑屏，可能是受保护画面或反作弊渲染阻止了 GDI 截屏；先试无边框窗口，或改用网页版上传。

### 选到了「未知英雄」

自动识别是**闭集字库**：60 个英雄名共 155 个汉字，每个字用 16×16 字模匹配；任一字不在字库或不在 top-5，整名返回 `null`，不会瞎猜。

`data/art` 里的 300×300 立绘只用于显示，不参与识别；识别读 `data/recognize/glyphs.json`。按 [USER_GUIDE 的手动修正步骤](USER_GUIDE.md#手动修正与学习新英雄) 补字模或修正英雄。

### 画面只有 3 个英雄和 8 个底栏图标

这现在是**正常且受支持**的布局，新方案正好只用这两处：

- 顶部前 3 个英雄名牌 → 字模识别；
- 底部 8 个书包图标 → 色度识别 8 启用，剩下 5 个自动作为禁用；
- 不需要右下角 13 流派面板，也不检测红色禁环。

如果这种画面下没有自动出结果，按顺序检查：

1. 控制台是否显示「自动识别已开启」；旧进程可能还是旧版。
2. 底部 8 个图标是否完整、没有被窗口裁掉；顶部前 3 个名牌是否完整。
3. 游戏窗口标题是否包含「选技大乱斗 / Skill Legends / 选技」；自动抓帧只认标题匹配的窗口。
4. 画面是否还在入场动画/翻牌；稳定门要求最近 3 个帧对差异 < 0.02。
5. 想立即重算按 `Alt+C`；如果完全没反应，看控制台是否报 `window_not_found` 或 `black_frame`。

### 流派识别错 / 不是 8 启用 5 禁用

- 确认底部 8 个图标完整，且没有被鼠标指针/飘字长时间遮住。
- 新方案用归一化色度 + 一对一约束；某个槽位 margin 不足时会返回 `partial`，只给高置信启用子集，`banned=null`，不猜禁用。
- 游戏大版本改 UI 后，更新 `data/recognize/layout.json` 的两个 ROI，并用 `tools/calibrate_thresholds.py` 重新标定 `margin_min`。
- 网页版可以手动切换流派；最终必须保持 8 启用、5 禁用。

### 置信度低 / 推荐不准

- 没有攻略或分数接近时，置信度会降低，这是正常的保守行为。
- 评分不是官方胜率，差几分不代表胜负。
- 检查英雄是否选对、8/5 流派是否符合实际。
- 攻略库可以在网页里补充或修正。

## 显示

### 浮窗一会儿就消失

当前版本不会自动隐藏。如果仍消失：

- 确认运行的是最新版本，旧进程可能还是自动隐藏的旧逻辑。
- 关闭旧控制台，重新启动。
- 检查是否误按了隐藏键。

### 浮窗跑到屏幕外 / 找不到

- 按隐藏键再显示，通常会用上次保存的位置。
- 删除 `data/overlay_position.json`，下次启动回到默认位置。
- 多显示器切换后，位置可能落在已断开的显示器；删文件最稳。

### 浮窗挡住游戏 / 不能点击游戏

- 按住卡片任意位置拖到角落。
- 按 `Alt+X` 隐藏，游戏完全不被遮挡。
- 当前浮窗是普通置顶窗口，为了支持拖动会接收鼠标；不再是点击穿透。拖动或隐藏即可。

### 图鉴不显示英雄立绘

1. 必须打开 `http://127.0.0.1:8777/library`，不能直接双击 `static/library.html`。
2. 关闭所有旧助手/网页控制台，重新运行 `启动助手.bat`。
3. 浏览器按 `Ctrl+F5`。
4. 打开 `http://127.0.0.1:8777/api/art-check`，正常返回：

```json
{"ok":true,"heroes":60,"art":60,"talent_icon":60,"ultimate_icon":60,"missing":[]}
```

- `art` 为 0：还在跑旧版服务，重启。
- `art` 为 60 但页面没图：按 F12 看 Network 里 `/data/art/...` 是否 404；同时确认浏览器没有拦截本地请求。
- 页面顶部出现红色提示时，按提示处理；新版本会显示服务端版本和素材数量。

### 英雄图鉴 / 卡牌库页面 404

- `/library` 由本地服务提供；确认服务在运行，且端口正确。
- 旧版服务可能没有图鉴页面；重启到最新版本。
- 如果 8777 被占用，实际端口可能已是 8778+，看控制台或 `data/server_url.txt`。

## 性能

### 识别比 1 秒慢很多

- 首次识别要加载 60 篇攻略和模板，通常比后续稍慢。
- 高分辨率截图、机械硬盘、杀毒软件扫描会有影响。
- 浮窗本身不调用 AI；AI 点评只在网页点按钮时请求，不影响识别速度。
- 可用 `--no-save-capture` 关闭每次截图落盘。
- 1280、900、2560 宽都测过；更极端的超宽屏可能需要调整 `--hud-scale`。

### CPU / 内存占用高

- 正常待机应很低；异常高时先关闭旧实例。
- 识别是短时 CPU 峰值，结束后应回落。
- 长时间运行可定期重启控制台。

## 端口 / 网络 / AI

### 端口 8777 被占用

会自动顺延到 8778 及之后。实际地址看控制台，或读 `data/server_url.txt`。不要手动改浏览器地址到旧端口。

8765 是另一个项目「记账本」的默认端口，助手默认避开它。

### 网页能打开但接口报错

- 旧服务可能没有新接口；重启。
- 看 `/api/status` 和 `/api/art-check` 是否返回 JSON。
- 浏览器插件、代理或安全软件可能拦截本地请求；先换浏览器或用无痕窗口。

### AI 点评失败

- AI 是可选功能，不配置不影响识别和推荐。
- 检查 API 地址、模型名和 Key；Key 只保存在本机 `data/settings.json`。
- 超时/限流时稍后重试；浮窗不会自动调用模型。

## 数据与攻略

### 新加的攻略不生效

- `hero` 字段必须与 `data/heroes.json` 的 `name` 完全一致。
- 用 `##` 二级标题分段；保存后网页会重建索引。
- 下一次识别会重新加载；如果仍不生效，重启助手。
- 知识库维护和核验见 [攻略知识库维护说明](攻略知识库维护README.md)。

### 卡牌数值和游戏里不一样

源表只提供基础值，`{valN}` 按基础值 × N 展示；实际以游戏内卡牌等级为准。规则和占位符核对见 [规则与数据核对](规则与数据核对.md)。

## 安全

默认只监听 `127.0.0.1`，截图只在内存和 `data/captures/last.png` 中处理，不上传。唯一的外部请求是主动开启的 AI 点评。`data/settings.json` 已被 `.gitignore` 排除。

如果以上都没有解决，请提供：控制台第一屏、`/api/art-check` 返回、F12 Network 中失败请求的状态码，以及问题发生的页面/操作。
