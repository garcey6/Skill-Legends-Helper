# 社区来源与版本差异

检索截至2026年11月9日。英雄和卡牌数值以用户指定仓库的数据快照为基准；基础游戏规则以仓库原始规则文件核对；下面的玩家构筑用于产生和检查玩法假设。官方公告单独列为版本证据。

本轮取得了11月鼠王构筑，但没有找到覆盖全部60位英雄的、同版本且有可靠对局统计的统一榜单。未取得对应社区资料的英雄，攻略明确标为机制推导。7—8月帖不冒充当前版本共识。

## 采用与不采用的部分

- 神秘法师帖子支持大招与精灵的搭配思路，但其被动数字与仓库不同。攻略用仓库的50%逐次增幅与300%上限，不用帖中的30%和150%。
- 疾影剑卫8月帖采用旧参数；本次采用仓库的消耗30%急速与每层200%系数，10月公告可交叉核对。
- 鼠王11月帖提出毒冰路线及无盾条件。本文采用候选路线，但不把帖中的伤害频率倍数视为必然成立，尤其不允许炸药无限自触发。
- 周期循环的精确优先级与所谓无限循环缺少本仓库的实现证据。攻略保留这条社区路线，标出循环目标竞争，不用它推算保证输出。
- 鬼牌帖中的部分文字把最大生命偷取解释为直接回血。本次遵从英雄原文，把最大生命与当前生命区分。
- 8月强度帖只代表作者的版本体验；没有对局样本、分层胜率和11月复核，不能据此判定某流派永久强或弱。
