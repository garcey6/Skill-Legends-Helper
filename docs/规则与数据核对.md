# 规则与数据核对

本攻略以仓库提交 `2922416928acb75c3059f9aae677d81ea63bfd6b` 为数据基准，检索日期为2026年11月9日。英雄文件自标2026.11，流派文件仍自标2026.10；这两个标签不自动证明所有字段都经过同一版本校正。

## 卡池结构

源表有60位英雄、156种卡、13个流派。全库去重为普通104种、稀有39种、传奇13种；每个流派按两个归属字段合并后，恰好包含普通14种、稀有3种、传奇1种。

78张普通卡同时属于两个流派。因此总归属数是234，不是234张独立卡；156种卡才是全库独立记录数。本快照中任意两系共享1种普通卡，两系候选池去重后为27普通、6稀有、2传奇，共35种。

18种是一个流派的候选目录，不是要求每局携带18张。普通、稀有、传奇的 `rarity_id` 分别为1、2、3；“传奇”与数据库用词“传说”在本文指同一稀有度。源表 `total_count` 为普通15、稀有9、传奇3，导入后名为 `pool`，它是记录的卡池数量，不是单个玩家的卡槽数或升级倍率。

## 13流派机制与ID

|数字ID|程序ID|流派|采用的机制边界|
|---|---|---|---|
|1|basic|普攻|攻击力、普攻频率及按普攻事件触发的卡。攻速是否有用先看英雄普攻规则。|
|2|dodge|闪避|每点对应1%闪避率；默认只有物理伤害能被闪避。魔法闪避卡有自己的概率。|
|3|crit|暴击|每点对应1%暴击率；默认物理伤害可暴击，基础暴击伤害为200%。|
|4|life|生命|最大生命与生命相关的技能缩放。当前生命、已损失英雄生命和玩家生命是不同变量。|
|5|heal|回复|治疗与治疗事件触发的卡；治疗量与治疗次数不能混算。|
|6|ultimate|大招|初始能量0，满100自动施放；失去生命也会回能。附带能量效率、回能与按施放次数触发的组件。|
|7|poison|中毒|每0.7秒按当前层数结算伤害，同时降低层数。基础机制不是按目标最大生命百分比伤害。|
|8|freeze|冰冻|降低攻速和弹道飞行速度；每秒降低层数，与急速抵消。冰冻不等同于眩晕。|
|9|shield|护盾|每层对每次伤害提供1点减伤，神圣伤害除外；结算后层数降低，与易伤抵消。|
|10|vulnerable|易伤|每层对每次非神圣伤害额外增加1点，结算后层数降低，与护盾抵消；不能笼统称为百分比乘区。|
|11|spirit|精灵|学精灵技能默认有50生命精灵，分担30%伤害；多精灵共同分担，不是每只独立再分担30%。|
|12|rage|怒气|损血增加怒气；100怒气进入2.5秒狂怒，伤害增幅最多85%，结束归零。|
|13|haste|急速|加快周期技能释放，每秒降低层数，与冰冻抵消；不能直接等同于普攻攻速。|

其中普攻、生命、回复的概括由卡牌条目归纳；其他具体数值主要来自原始[游戏规则文件](../data/source/游戏规则.txt)。精灵伤害分担、回复转盾、额外施法等若与英雄特殊文本相遇，以特殊文本为先，未给出的结算顺序保留不确定性。

## 品阶和数值倍率

数据库没有提供普通、稀有、传奇的完整等级成长表，也没有单独定义 `{val4}` 等占位符。因此本次不能给出经过核实的“各品阶每级倍率”。

|概念|已知内容|本文处理|
|---|---|---|
|稀有度|1普通、2稀有、3传奇|分类，不乘到伤害上|
|基础值|每卡只有 `base_val_1`|用于替换明确的 `{val}`|
|`{valN}`|原项目导入器按基础值乘N展示|属于项目假设，攻略保留占位符，不当成游戏升级规则|
|升级、满级、升金|无完整表|不外推满级数值、成本或概率|
|固定文字传奇|基础值经常为0|按描述中的固定数值生效，不能解释成零效果|
|基础暴击倍率|规则文件为200%|与英雄天赋、卡牌升级倍率分开处理|

含未定义 `{valN}` 的卡牌ID为：110、111、114、115、116、157、158、178、191、241、247。例：攻击急速基础值4，模板写 `{val4}`，原项目展示为16；这个转换由导入器决定，源表并未说明它是四倍、四级值还是其他索引。因此攻略直接保留 `{val4}`，需要客户端或补充表才能定值。

## 双流派共享规则

确定的部分是同一 `card_id` 可以有两个归属；按任一归属检索可找到它，合并两个流派必须按ID去重，不能把同一张卡的伤害、卡池总量或技能种类复制两次。

项目 `app/kb/cards.py` 的注释假定共享卡能推进两系，运行时又会按主归属过滤部分被禁卡。源表没有明确双系经验分配、只开放其中一系时的商店出现条件，也没有说明淘汰后的返还比例。本文把这些列为待核实规则，而不是选择性沿用项目推测。尤其“卡牌目录去重”与“盾伤打击文字里的两系种类数怎么计”不是同一个问题。

## 选卡方法

1. 从天赋与大招提取触发事件、资源、伤害类型和明确的排除条件。
2. 选择1个能提供主要收益的流派与1个可连接触发链或补生存的流派。
3. 按两归属筛出各自14普通、3稀有、1传奇；合并清单时去重。
4. 优先低依赖启动卡和本英雄关键卡，再补稀有转化组件，最后按实际战斗决定传奇与反制。
5. 没有触发源的共享卡降优先；不能只因为“同时属于主副流派”就认定它必强。
6. 重新核对当前开放流派、已拿卡、经济、宝物和对手；这些未提供时，本文只给条件方案。

P0是本方案关键组件，P1是常规补强，P2是需要已有触发条件的补牌；对局反制单列。各品阶内部顺序由英雄专属重点卡与流派用途共同决定，不把传奇自动放到开局第一抓。

## 数据异常与现有软件边界

- 冰霜法师大招末尾有“花费600解锁300”杂字；鱼人咒术士、霜影暴君等条目也有文字错误。原始快照保留，推导不把明显界面杂字当技能数值。
- 英雄 `power`、`tier`、`schools`、`weak_to` 是作者示例或估算，不能作为本次论证的事实依据。本次重新逐位解释流派选择，不生成伪精确胜率。
- 本攻略生成器不改写原项目评分。增加知识库覆盖后，原程序可能因为“有攻略”而提高自身置信度标签，这并不代表攻略经过实战验证。
- 原项目短卡片与图鉴6张核心卡仍来自原排序器；完整14＋3＋1表和机制例外应在攻略正文查看。
- 本次卡组是技能文本分析，未进行真实游戏对局、伤害模拟或卡池概率验证。
